# Guía Docente · Maestría en Ciencia de Datos y Máquinas de Aprendizaje (UTM)

Guía para docentes de la Maestría en Ciencia de Datos y Máquinas de Aprendizaje, Facultad de Posgrado, Universidad Técnica de Manabí.

Es una página estática de un solo archivo (`index.html`), sin dependencias de compilación. Usa la fuente Poppins desde Google Fonts.

## Pasos de la guía

1. Requisitos para la contratación
2. Antes de empezar la asignatura
3. Durante la asignatura
4. Proceso de titulación (proyecto de investigación (tesis), artículo de alto nivel y examen complexivo)
5. Checklist para pagos

## Contenido pendiente

Los datos marcados como "pendiente" en la página (enlaces de formatos, correo de pagos, fecha límite) se completan editando `index.html`.

## Ver en local

Abre `index.html` en el navegador.
